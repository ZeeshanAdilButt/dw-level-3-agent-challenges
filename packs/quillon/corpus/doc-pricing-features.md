# What each plan includes

## Scope and effective date

This document sets out which features are included in each Quillon plan for contract-management software. It is a public pricing rule and takes effect on 2026-07-01. Where a feature is not listed as included for a plan, it is not part of that plan's price.

## Feature matrix

The table below shows each feature against each plan. "Included" means the feature is part of the plan price. "Add-on" means the feature is sold separately. "Not available" means the feature cannot be purchased for that plan.

| Feature | Starter | Team | Pro | Enterprise |
|---|---|---|---|---|
| Drafting from templates | Included | Included | Included | Included |
| Clause library | Included | Included | Included | Included |
| Approval workflows | Single approver step | Multi-step approval workflows | Multi-step approval workflows | Multi-step approval workflows |
| E-signature | Included | Included | Included | Included |
| Obligation tracking | Not available | Included | Included | Included |
| Renewal alerts | Included | Included | Included | Included |
| Full-text search across signed contracts | Included | Included | Included | Included |
| AI clause review | Paid add-on | Paid add-on | Paid add-on | Paid add-on |
| SAML single sign-on | Not available | Not available | Included | Included |
| SCIM provisioning | Not available | Not available | Not available | Included |
| REST API | Not available | Not available | Included | Included |
| Customer-managed encryption keys | Not available | Not available | Not available | Included |
| Standard seat cap | Not stated in this table | 25 seats | Not stated in this table | Not stated in this table |

## Plan-specific notes

Approval workflows differ by plan. The Starter plan includes a single approver step for each contract. The Team plan and every plan above it include multi-step approval workflows, so a contract can pass through several reviewers in a set order before it is released for signature. Obligation tracking, which records dates and duties that arise after a contract is signed, is included from the Team plan upward and is not available on Starter.

Single sign-on and API access are reserved for the Pro and Enterprise plans. SAML single sign-on is available on the Pro and Enterprise plans, and the REST API is available on the Pro and Enterprise plans, so customers who need either capability must choose one of those two tiers. SCIM provisioning and customer-managed encryption keys are available on the Enterprise plan only. Customers who need automated user provisioning or control over their own encryption keys should contact Quillon about the Enterprise plan.

Renewal alerts and full-text search across signed contracts are included on every plan. AI clause review is a paid add-on on every plan and is not included in any plan price, so customers who want it must purchase it separately regardless of tier.

The Team plan (PLN-TEAM-25) carries a standard seat cap of 25 seats. Customers who need more seats than the standard cap should contact Quillon to discuss their options before purchase.
