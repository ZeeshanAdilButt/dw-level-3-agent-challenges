# Release 2025.12

## Headline

Release 2025.12 adds bulk export of signed contracts as ZIP bundles, so teams can move large sets of executed agreements out of Quillon in a single step.

## What changed

- Bulk export: Users can select a set of signed contracts from search results or a folder and export them together as ZIP bundles. Each bundle contains the executed contract files along with a summary index listing the contract titles, parties, and signing status.
- Export scope: Bulk export applies only to contracts in a signed state. Drafts and contracts awaiting signature are not included in the bundle, which keeps exported records limited to final agreements.
- Access controls: Bulk export respects existing workspace permissions. A user can export only the contracts they are already allowed to view, and export activity is recorded in the audit log.

## Other improvements

The release also includes general performance and stability fixes to search across signed contracts, and clearer labels on the approvals screen so reviewers can see which step they are responsible for. No changes were made to e-signature workflows, obligation tracking, or renewal alerts in this release.

## Who is affected

Administrators and legal operations staff at law firms and corporate finance teams who manage large volumes of signed agreements will find bulk export most useful. Individual users see no change unless they use the new export option from search results or folders.

## Getting started

Bulk export is available to all workspaces on the current plan without any setup. Users with export permissions can find the option in the toolbar that appears after selecting multiple signed contracts. Questions about the release can be directed to your Quillon account contact or the support center.
