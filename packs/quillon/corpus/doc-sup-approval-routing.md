# Route approvals

This guide explains how to send a draft contract through an approval chain in Quillon, and what to do when an approver is unavailable. It is effective from 2026-07-15.

## Before you start

Approvals run on the contract version you select, so make sure the draft is final before routing it. Only the contract owner or a member with editing rights can start an approval request.

## Steps to route a contract for approval

1. Open the contract from your workspace and select the version you want reviewed.
2. Select "Request approval" from the contract actions menu.
3. Add approvers in the order they should review the contract. Parallel approvals can be set for approvers who do not depend on one another.
4. Add a short note explaining what you need from each approver.
5. Select "Send for approval" to notify the first approver.
6. Track progress in the approval panel, where each step shows as pending, approved, or returned.
7. If an approver returns the contract, revise the draft, then select "Resubmit" to restart the chain from the step that returned it.

## Delegating an approval

An approver can delegate to a deputy for up to 30 days if they expect to be away. Open the approval request, select "Delegate," choose the deputy, and set the end date. The deputy receives the request immediately and the original approver remains on the record.

## Tip

Set the delegation end date before you leave, not after. Delegations that end on time return the approval to the original approver automatically, so no requests are left waiting.
