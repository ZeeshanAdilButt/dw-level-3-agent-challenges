# Supported browsers

## Overview

Quillon supports the latest two versions of Chrome, Edge, Firefox and Safari for all drafting, approval, e-signature, and search features. Using a supported browser helps ensure that templates, the clause library, and signed contract views load correctly for your team.

## Checking your browser version

1. Open the browser you use to sign in to Quillon.
2. Open the browser menu and select the About or Help option.
3. Read the version number shown on the screen.
4. Compare the version with the latest two releases listed for that browser in this guide.
5. If your version is older, select the update option in the same menu and restart the browser.
6. Return to Quillon and reload the page.

## Steps if a feature does not load

1. Confirm that your browser is one of the four supported browsers.
2. Confirm that you are using one of its latest two versions.
3. Clear the cache for the Quillon site and sign in again.
4. Disable any browser extensions that block scripts or pop-ups, then reload the page.
5. If the problem continues, contact the support team and include your browser name, version, and a short description of the issue.

## Tip

Keep automatic updates turned on for your browser so that you receive the latest supported version without manual steps.
