# Release 2026.06.1

Effective from 2026-06-23

## Summary

Release 2026.06.1 fixed duplicate renewal alerts for contracts with two owners. Previously, a contract assigned to two people could trigger the same renewal reminder twice, which created noise for both owners and sometimes led to duplicate follow-up tasks. Each contract now produces one renewal alert per renewal window, delivered to all assigned owners together.

## Changes in this release

The release includes the following updates:

- Duplicate renewal alerts are no longer generated for contracts with two owners. Each renewal window produces a single alert.
- Owners of shared contracts now see the same alert status in the obligation tracker, so no one needs to reconcile separate notifications.
- Existing duplicate alerts raised before this release are cleared automatically when the contract is next synced. No action is needed from administrators.

## Who is affected

This release affects administrators and users who manage contracts with more than one owner in the renewal alerts feature, primarily corporate finance teams and law firm matter leads. Single-owner contracts are unchanged.
