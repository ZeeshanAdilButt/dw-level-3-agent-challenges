# Release 2026.01

## Headline

Release 2026.01 adds tags to clauses in the clause library, making it easier for drafting teams to find, group and reuse standard language across templates.

## What changed

- Clause tags: Release 2026.01 added tags to clauses in the clause library, so users can label a clause by topic, jurisdiction, risk level or business owner and filter the library by those labels.
- Tag-based search: Search within the clause library now returns results that match a tag as well as clause titles and body text, so a clause can be located without knowing its exact name.
- Template linking: When a clause is inserted into a template, its tags carry over, which lets reviewers see at a glance where a given topic appears across drafts.

## Who is affected

Legal operations leads, contract managers and drafting teams who maintain clause libraries will see the new tagging controls first. Existing clauses remain unchanged until a user adds tags, and no action is required to keep current templates working.

## Getting started

Administrators can open the clause library, select any clause, and use the Tags field in the clause properties panel to add or remove labels. Tags are shared across the workspace, so a label added by one team is visible to everyone with library access. Our help center describes naming conventions that many teams use to keep tags consistent over time.
