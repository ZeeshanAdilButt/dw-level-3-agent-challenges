# Order form template

## Purpose and scope

This order form template governs the purchase of Quillon contract-management software (SaaS) by law firms and corporate finance teams. The current order form template is coded OF-2026-A, and it applies to all new orders and renewals effective from 2026-07-01. Each order placed under OF-2026-A is subject to the terms of the master subscription agreement between Quillon and the customer.

## Key values

| Item | Value |
| --- | --- |
| Template code (OF-2026-A) | Current order form template version |
| Quote validity period (30 days) | Duration a quote stays valid from the day it is issued |
| Quote validity (thirty days) | Written form of the same quote validity period |
| Required order form fields | Plan code, seat count, billing period, term start date |

## Quote validity

A quote stays valid for 30 days from the day it is issued. After that period, the quote expires and Quillon may reissue it at current terms. A customer who signs an order form before the quote expires is bound by the quoted terms for the term stated on that order form.

## Required fields

Every order form states the plan code, the seat count, the billing period and the term start date. Quillon will not process an order form that omits any of these fields. The table below explains what to enter in each field.

| Field | What to enter |
| --- | --- |
| Customer legal name | The full registered name of the contracting entity |
| Plan code | The code of the Quillon plan selected for the order |
| Seat count | The number of named users who will access the product |
| Billing period | The interval at which fees are invoiced |
| Term start date | The date on which the subscription begins |
| Authorized signatory | Name and title of the person signing for the customer |
| Billing contact | Email address for invoices and payment notices |

## Signing steps

1. Confirm the quote is within its validity period and has not expired.
2. Enter the customer legal name exactly as registered.
3. Enter the plan code from the approved quote.
4. Enter the seat count, which may be increased later under the change terms of the agreement.
5. Enter the billing period and the term start date.
6. Complete the authorized signatory and billing contact fields.
7. Review the completed order form against the quote for any mismatch.
8. Send the order form for electronic signature through the Quillon signing workflow.
9. Store the countersigned order form in the customer record, where it becomes searchable with the rest of the signed contract set.
10. Quillon issues confirmation and schedules the first invoice on the term start date.

## General terms

Changes to seat count, plan code or billing period after signature require a new order form under the current template. Quillon will issue renewal alerts before the end of each term so that customers can review terms before automatic renewal. Questions about this template may be directed to the Quillon commercial team.
