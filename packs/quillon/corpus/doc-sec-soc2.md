# SOC 2 Report

## Purpose

This document describes Quillon's SOC 2 Type II report, what it covers, and how customers and prospective customers can obtain it. Quillon provides contract-management software to law firms and corporate finance teams, including drafting from templates, a clause library, approvals, e-signature, obligation tracking, renewal alerts, and search across signed contracts. The controls described in the report apply to the systems that support these functions.

## Availability of the Report

The SOC 2 Type II report is available to customers under NDA on request. Customers and prospective customers can ask their account representative or the Quillon security team for a copy, and the security team will confirm the NDA terms before the report is shared. The report is not published on a public website because it contains detailed descriptions of internal controls.

## Audit Period

The latest SOC 2 Type II audit period ended on 31 March 2026. The audit period is the window during which the independent auditor tested whether Quillon's controls operated effectively over time. A Type II report therefore reflects operating effectiveness across that window, not only a single point in time.

## Scope of the Report

The report covers the Quillon platform and the supporting infrastructure, personnel, and processes used to deliver the service. Within this scope, the report addresses the Trust Services Criteria selected for the engagement, which relate to security, availability, confidentiality, and processing integrity as applicable to the service. Customers reviewing the report should read the system description and the scope section, because controls outside the described system are not covered.

The table below summarises the report at a high level.

| Item | Summary |
|---|---|
| Report type | SOC 2 Type II |
| Audit period end | 31 March 2026 |
| Availability | Under NDA, on request |
| Covered service | Quillon contract-management platform |
| Intended readers | Customers and prospective customers under NDA |

## Requesting a Copy

To request the report, contact the Quillon security team through your account representative. Include the name of your organisation and the name of the person who will receive the report. The security team will send the NDA for signature. Once the NDA is executed, the report is provided through a secure channel. Requests are handled as part of normal customer security review.

## Limitations

The SOC 2 report is an independent auditor's opinion on the controls described in it at the stated audit period. It does not guarantee that no security incident will occur, and it does not cover changes made after the audit period ended except where the report states otherwise. Customers should consider the report alongside their own due diligence, contractual terms, and the controls they operate on their side of the relationship.

## Questions

Questions about this document or the report should be directed to the Quillon security team through the customer support channel or the account representative.
