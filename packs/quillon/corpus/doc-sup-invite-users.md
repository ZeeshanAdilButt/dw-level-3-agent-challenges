# Invite and remove users

## Purpose

This guide explains how workspace administrators invite new users to Quillon and remove users who no longer need access. Only users with the administrator role can invite or remove users.

## Before you begin

Confirm that you have the administrator role in your workspace. If you do not see the Users section in Settings, ask an existing administrator to grant you the role.

## How to invite a user

1. Sign in to Quillon and select Settings from the account menu.
2. Select Users, then select Invite user.
3. Enter the person's work email address and choose a role for them.
4. Select Send invitation. The invitee receives an email with a link to join your workspace.
5. Ask the invitee to open the link and create their account. Invitation links expire after 7 days, so resend the invitation if the link has lapsed.
6. Confirm the new user appears in the Users list with the status Active.

## How to remove a user

1. Open Settings, then select Users.
2. Find the user in the list, or use the search box.
3. Select the menu beside their name, then select Remove from workspace.
4. Confirm the removal. The user loses access immediately, but their contracts remain in the workspace.

## Tip

Remove users on their last working day so that access does not outlive their employment, and review the Users list each quarter to catch accounts that are no longer needed.
