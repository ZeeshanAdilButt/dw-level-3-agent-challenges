# Insurer billing codes

## Purpose and scope

This document sets out the billing codes that Juniper Lane Clinic uses when submitting insurer claims for services delivered at the Port Avery practice. It covers family medicine, child health checks, vaccinations and the travel clinic, blood tests, physiotherapy, women's health, minor procedures, repeat prescription administration and telehealth calls. Staff in reception, clinical support and the billing team must use the codes listed here and must not substitute codes from memory or from older versions of this document.

## Effective date and authority

This rule takes effect on 2026-04-01 and replaces any earlier insurer billing code list held at the practice. It is issued under the authority of the practice manager and the billing lead. Questions about a code, or reports that a code has been rejected by an insurer, should go to the billing lead before any resubmission.

## Insurer billing codes

Each insurer has one billing code that must appear on every claim sent to that insurer. The table below lists the code for each insurer that the practice currently works with.

| Insurer | Billing code for claims | Notes |
|---|---|---|
| Harbourline Health | HL-204 | Applies to all claim types listed in the scope section |
| Tidewell Cover | TW-118 | Applies to all claim types listed in the scope section |
| Pinegate Assurance | PG-330 | Applies to all claim types listed in the scope section |
| Larkfield Friendly Society | LF-072 | Applies to all claim types listed in the scope section |
| Copperbeech Care | CB-509 | Applies to all claim types listed in the scope section |

Where a patient is covered by more than one insurer, the billing team must confirm the primary insurer at registration and apply that insurer's code to the primary claim. Secondary claims follow the same rule using the secondary insurer's code.

## Claim batching schedule

Insurer claims are not sent individually as they are completed. They are gathered and sent as a single batch once a week. Insurer claims are sent in a batch every Friday at 14:00. Claims completed after that cut-off move to the following week's batch. Clinicians who finish a consultation late on a Friday should flag any urgent claim to the billing lead so that it can be checked before the batch is released.

## Handling rejected or returned claims

When an insurer returns a claim, the billing team records the reason, corrects the error and resubmits the claim in the next batch unless the insurer asks for a faster route. The billing code must be checked first, since an incorrect or missing code is one of the most common reasons for return. Repeated returns from the same insurer should be reported to the billing lead so that the pattern can be reviewed.

## Responsibilities

The billing lead owns this document and keeps the table of codes accurate. Reception staff are responsible for confirming insurer details at registration. Clinicians are responsible for providing complete and accurate service records before the claim is prepared. The practice manager reviews this document whenever an insurer changes its arrangements with the practice.
