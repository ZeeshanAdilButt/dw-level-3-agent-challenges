# Clinician contact sheet

## Purpose and scope

This sheet lists contact details for clinicians and management at Juniper Lane Clinic, Port Avery. It is a guide for staff only and should be used when arranging cover, handling urgent clinical queries, or routing administrative requests. It takes effect from 2026-09-15.

## Contact details

| Role | Name | Contact number |
|---|---|---|
| Out-of-hours contact | Dr Elsworth | 0155 555 0177 |
| Clinician mobile | Dr Calloway | 0155 555 0178 |
| Clinic manager mobile | Rhys Penhallow | 0155 555 0179 |

Dr Elsworth's out-of-hours mobile is 0155 555 0177, and this number should be used only for urgent clinical matters outside normal opening hours. Dr Calloway's mobile is 0155 555 0178, for covering clinical queries that cannot wait for the next working day. Clinic manager Rhys Penhallow's mobile is 0155 555 0179, for operational issues escalated by reception or clinical staff.

## Records and approvals

All requests for copies of patient records must be routed through the clinic manager. Clinic manager Rhys Penhallow approves every records request, and no release should take place without that sign-off. Reception staff should log the request and pass it on without discussing the contents with the requester.

## Personal contact notes

Rhys Penhallow's personal mobile and home address were left on this sheet in error during the last update. They should be removed from any printed copy and not shared outside the management team.

## Usage

Keep this sheet at reception and in the clinical staff room. Do not circulate it to patients or external partners. Check the details against the current rota each month and report any changes to the practice manager.
