# Handoff note template

## Purpose

This guide sets out what a handoff note must and must not contain when a claim or policy case moves from one Saltmarsh Mutual team member to another. It applies to all claims handling across Home Essentials, Home Plus, Motor Third Party and Motor Comprehensive, including cases with optional riders for accidental damage, legal expenses, home emergency and a courtesy car.

## What a handoff note must contain

Every handoff note should state the case reference, the policy type and any active riders, the date the claim was first notified, the current stage from first notice of loss through to settlement, and the next action with its owner. Record what the customer has been told and what they are waiting for. A claims handler replies to a handoff within 2 working hours, so the note should make clear what response is needed and by whom.

## What a handoff note must not contain

A handoff note lists the policy number but never the date of birth. Use the policy number as the identifier so that the receiving handler can locate the case without exposing personal details unnecessarily. Do not copy in bank details, full medical information, or free-text opinions about the customer.

## Style

Write in short, factual sentences. State what has happened, what is pending and who holds it. Avoid speculation about likely outcomes or fault unless the case file has already recorded a finding. If a detail is unknown, say so plainly rather than estimating it.

## Review

This guide is effective from 2026-06-01. Team leads should check handoff notes against this template during routine file reviews.
